# Pictures that need a better original

12 pictures on this site are being enlarged by the layout. The file
on disk is already the biggest one there is, so no amount of code makes them
sharper — each one needs a larger photograph in its place.

**Enough** is the width the picture is drawn at, which stops the enlarging.
**Ideal** is twice that, which is what a modern phone or laptop screen actually
draws. For a full-width backdrop, enough is genuinely enough — doubling a
1600px background buys a sharpness nobody looks at and costs every visitor the
download.

Replace a picture by uploading the new one in the editor on the page listed.
The site picks up the larger file on the next publish with no other change.

A graphic carrying small text — an infographic, a scan of a document — suffers
most from being enlarged, because the letters go soft before anything else
does. A portrait at the same ratio is barely affected. Work down the list with
that in mind rather than strictly by number.
